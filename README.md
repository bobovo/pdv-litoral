# PDV Litoral SC

Sistema de ponto de venda (PDV) offline desenvolvido para pequenos comércios.

## 🚀 Funcionalidades
- Registro de vendas
- Controle de produtos
- Cálculo automático de total
- Histórico de vendas
- Funcionamento offline (sem internet)

## 🧠 Contexto real
Sistema desenvolvido e utilizado em duas lojas físicas:
- Loja de embalagens
- Loja de sandálias

## 🛠️ Tecnologias
- JavaScript
- Node.js
- SQLite (sql.js)
- HTML / CSS

## 💻 Execução
Rodar servidor:
node server/server.js

Acessar:
http://localhost:3000/pdv
